# SlideForge

**Бесплатный AI-генератор презентаций.** Вводишь тему — моментально получаешь готовую презентацию со слайдами, текстом и картинками. Без регистрации, без подписок, без ограничений.

## Что умеет

- Генерирует структуру и контент презентации с помощью AI (GigaChat)
- Подбирает изображения для каждого слайда
- Показывает живой прогресс генерации в реальном времени
- Отдаёт готовый файл **`.pptx`** для скачивания
- Показывает готовую презентацию сразу в браузере
- Ссылка на презентацию, которой можно поделиться
- 5 стилей оформления: минимализм, академический, креативный, корпоративный, тёмный
- От 5 до 25 слайдов
- Интерфейс на русском и английском, светлая/тёмная тема
- Полностью адаптивно — работает на телефоне, планшете и десктопе

## Технологии

- **Frontend:** React + Vite + Tailwind CSS + Framer Motion
- **Backend:** Python + FastAPI
- **AI:** GigaChat API (Сбер)
- **Изображения:** Picsum Photos
- **Хостинг:** Render (бесплатный тариф)
